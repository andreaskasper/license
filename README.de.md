# FastFood License 🍔

**Eine moderne, auf Dankbarkeit fokussierte Open-Source-Lizenz**

## 🎯 Philosophie

Die FastFood License stellt **Dankbarkeit und Community** in den Mittelpunkt von Open Source. Statt rechtlicher Komplexität fokussieren wir uns auf die einfache menschliche Geste: Wenn dieser Code dir hilft, zeig deine Wertschätzung - vielleicht mit einem Kaffee, Burger oder einfach einem netten Wort.

> "Code ist besser, wenn er mit Dankbarkeit geteilt wird"

## 📦 Verfügbare Varianten

Wähle die Variante, die zu deinem Projekt passt:

### 🍟 FastFood Minimal (FFM)
**Am besten für:** Maximale Verbreitung, kommerzielle Nutzung willkommen  
**Ähnlich zu:** MIT License + Dankbarkeitskultur  
**Hauptmerkmale:**
- ✅ Kommerzielle Nutzung
- ✅ Freie Modifikation
- ✅ Closed-Source-Derivate erlaubt
- 💚 Zeig Dankbarkeit, wenn es dir hilft

→ [LICENSE-FFM.txt](LICENSE-FFM.txt)

### 🍔 FastFood Standard (FFS)  
**Am besten für:** Verbesserungen offen halten  
**Ähnlich zu:** GPL + Dankbarkeitskultur  
**Hauptmerkmale:**
- ✅ Kommerzielle Nutzung
- ✅ Freie Modifikation
- ⚠️ Derivate müssen Open Source bleiben
- 💚 Zeig Dankbarkeit, wenn es dir hilft

→ [LICENSE-FFS.txt](LICENSE-FFS.txt)

### 🌱 FastFood Ethical (FFE)
**Am besten für:** Werteorientierte Projekte  
**Ähnlich zu:** Hippocratic License + Dankbarkeit  
**Hauptmerkmale:**
- ✅ Kommerzielle Nutzung (mit Werten)
- ✅ Freie Modifikation
- ⚠️ Derivate müssen Open Source bleiben
- ⚠️ Nur friedliche, menschenrechtskonforme Nutzung
- 💚 Zeig Dankbarkeit, wenn es dir hilft

→ [LICENSE-FFE.txt](LICENSE-FFE.txt)

## 🚀 Schnellstart

### 1. Wähle deine Variante
Wähle die Lizenz, die zu deinen Werten und Projektzielen passt.

### 2. Füge sie zu deinem Projekt hinzu
```bash
# Lade die gewählte Lizenz herunter
wget https://raw.githubusercontent.com/andreaskasper/license/master/LICENSE-FFM.txt

# Benenne sie zum Standard-Dateinamen um
mv LICENSE-FFM.txt LICENSE
```

### 3. Aktualisiere die Platzhalter
Ersetze diese in der LICENSE-Datei:
- `[year]` → Aktuelles Jahr
- `[fullname]` → Dein Name
- `<email@example.com>` → Deine E-Mail

### 4. Füge sie zu Quelldateien hinzu (optional)
```javascript
// SPDX-License-Identifier: FastFood-Minimal-1.0
// Copyright (c) 2025 Dein Name <deine@email.com>
```

## 💡 Wege, Dankbarkeit zu zeigen

Wenn dieser Code dir geholfen hat, hier ein paar Ideen:

- 🍔 **Kauf uns einen Burger/Kaffee** (wenn wir uns treffen)
- ⭐ **Gib dem Repo einen Stern** auf GitHub
- 💬 **Schick eine Dankes**-Nachricht
- 🐛 **Melde Bugs** oder verbessere die Doku
- 🔗 **Teile das Projekt** mit anderen
- 💰 **Sponsore** via GitHub Sponsors (falls verfügbar)
- 📝 **Schreibe darüber** in deinem Blog
- 🎁 **Sende einen digitalen Geschenkgutschein**

**Denk dran:** Dankbarkeit ist optional, aber geschätzt. Die Lizenz verlangt es nicht!

## 🏛️ Rechtlicher Hinweis

**Dies ist keine Rechtsberatung.** Die FastFood License wird bereitgestellt wie sie ist. Du solltest:

- Für kritische Projekte einen Anwalt konsultieren
- Die Auswirkungen für deinen spezifischen Anwendungsfall verstehen
- Etablierte Lizenzen (MIT/GPL) für maximale Verbreitung in Betracht ziehen

Die FastFood License ist **nicht OSI-zugelassen** (noch nicht). Für Unternehmensumgebungen, die nur zugelassene Lizenzen erlauben, erwäge MIT + eine CODE_OF_CONDUCT.md, die deine Werte ausdrückt.

## 🤔 Warum FastFood License?

Weil:
- ✨ **Dankbarkeit wichtig ist** in Open Source
- 🤝 **Community** über Konzerne
- 😊 **Menschliche Verbindung** beim Code-Sharing
- 🍔 **Universelle Sprache** - jeder versteht Essen
- 🎯 **Flexibilität** - wähle, was zu deinen Werten passt
