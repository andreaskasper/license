# FastFood License 🍔

**A modern, gratitude-focused open-source license**

## 🎯 Philosophy

The FastFood License puts **gratitude and community** at the center of open source. Instead of legal complexity, we focus on the simple human gesture: If this code helps you, show your appreciation - maybe with a coffee, burger, or just a kind word.

> "Code is better when shared with gratitude"

## 📦 Available Variants

Choose the variant that fits your project:

### 🍟 FastFood Minimal (FFM)
**Best for:** Maximum adoption, commercial use welcome  
**Similar to:** MIT License + gratitude culture  
**Key features:**
- ✅ Use commercially
- ✅ Modify freely
- ✅ Closed source derivatives allowed
- 💚 Show gratitude if it helps you

→ [LICENSE-FFM.txt](LICENSE-FFM.txt)

### 🍔 FastFood Standard (FFS)  
**Best for:** Keeping improvements open  
**Similar to:** GPL + gratitude culture  
**Key features:**
- ✅ Use commercially
- ✅ Modify freely
- ⚠️ Derivatives must stay open source
- 💚 Show gratitude if it helps you

→ [LICENSE-FFS.txt](LICENSE-FFS.txt)

### 🌱 FastFood Ethical (FFE)
**Best for:** Value-aligned projects  
**Similar to:** Hippocratic License + gratitude  
**Key features:**
- ✅ Use commercially (with values)
- ✅ Modify freely
- ⚠️ Derivatives must stay open source
- ⚠️ Only peaceful, human-rights-respecting use
- 💚 Show gratitude if it helps you

→ [LICENSE-FFE.txt](LICENSE-FFE.txt)

## 🚀 Quick Start

### 1. Choose your variant
Pick the license that matches your values and project goals.

### 2. Add to your project
```bash
# Download the license file
wget https://raw.githubusercontent.com/andreaskasper/license/master/LICENSE-FFM.txt

# Rename to LICENSE (standard name)
mv LICENSE-FFM.txt LICENSE
```

### 3. Update placeholders
Replace these in the license file:
- `[year]` → Current year
- `[fullname]` → Your name
- `<email@example.com>` → Your email

### 4. Add to source files (optional)
```javascript
// SPDX-License-Identifier: FastFood-Minimal-1.0
// Copyright (c) 2025 Your Name <your@email.com>
```

## 🏛️ Legal Note

**This is not legal advice.** The FastFood License is provided as-is. While we've made it modern and practical, you should:

- Review with a lawyer for critical projects
- Understand the implications for your specific use case
- Consider using established licenses (MIT/GPL) for maximum adoption

The FastFood License is **not OSI-approved** (yet). For corporate environments requiring only approved licenses, consider MIT + a CODE_OF_CONDUCT.md expressing your values.

Because:
- ✨ **Gratitude matters** in open source
- 🤝 **Community** over corporations
- 😊 **Human connection** in code sharing
- 🍔 **Universal language** - everyone understands food
- 🎯 **Flexibility** - choose what fits your values
